Main directives

  • "Title" — section heading
  • 'comment — paragraph text
  • #deq expr @@(N) — displayed equation with numbering
  • #sym … #end sym — symbolic block
  • #function f(x;y) … #end function — user function
  • #hide / #show — hide/show definitions
  • #for i = 1 : n … #loop — loop
