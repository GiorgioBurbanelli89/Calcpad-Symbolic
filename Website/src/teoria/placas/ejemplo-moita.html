Ejemplo Moita — Placa isótropa cuadrada, validación

Fuente: Moita, J. S. — Método dos Elementos Finitos, §APLICACIONES "Placa quadrada isótropica simplesmente apoiada", p. 94-95.

Datos del problema

  • Geometría: a = b = 1.0 m, espesor h = 0.02 m
  • Material: acero E = 200 GPa, ν = 0.3, ρ = 7850 kg/m³
  • Carga: uniforme q = 50 000 N/m²
  • Apoyos: simples en los 4 bordes

Teoría aplicada — Principio de Hamilton

Para análisis dinámico, del principio de Hamilton resulta (Moita p. 92):

[KLe − ω² Me] {ae} = 0

Para vibraciones libres armónicas (Fext = 0, äe = −ω² ae). Los autovalores dan las frecuencias naturales ω y los autovectores los modos de vibración.

Fórmula analítica Navier (placa cuadrada apoyada)

ωmn = π² (m²/a² + n²/a²) √(D / ρh)  [rad/s]

Reproducción con el parser de Calcpad-Symbolic

  2. Flecha central con serie de Navier (9 términos impares)
  3. Tensión máxima de flexión
