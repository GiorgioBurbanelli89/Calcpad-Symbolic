Elemento triangular placa-cáscara (CST + DKT)

§5.3 Elemento triangular placa-cáscara

Fuente: Moita, J. S. — Método dos Elementos Finitos, §5.3 Formulação geral do MEF em estruturas do tipo placa-casca, p. 82-86.

Características

  • Elemento plano de geometría triangular.
  • Tres nodos en los vértices, 6 GDL por nodo (3 translaciones + 3 rotaciones) → 18 GDL totales.
  • Aplicable a estructuras placa-cáscara de paredes finas o semi-espesas.

Superposición de matrices

La formulación se obtiene por sobreposición de:

  1. Elemento de tensión plana de placa (membrana) → KM
  2. Elemento de flexión de placa (DKT) → KB
  3. Rotación según z (drilling DOF) → Kθz
K = KM + KB + Kθz

§5.3.2 Coordenadas de área

Un punto P dentro del triángulo se define por las coordenadas de área:

L1 = A1 / A  ;  L2 = A2 / A  ;  L3 = A3 / A
con L1 + L2 + L3 = 1

Relación con coordenadas cartesianas

Li = (ai + bi·x + ci·y) / 2A
a1 = x2·y3 − x3·y2 ;  b1 = y2 − y3 ;  c1 = x3 − x2
(permutación cíclica para a2, a3, etc.)

Coordenadas naturales

L1 = 1 − ξ − η ;  L2 = ξ ;  L3 = η (ξ, η ∈ [0, 1])

Funciones de forma

  • Membrana (CST) — lineales: Nim = Li → deformación constante.
  • Flexión (DKT) — cuadráticas en Li, una familia de 9 funciones: w0 = Σ [₁Ni   ₂Ni   ₃Ni] · {w0i; θxi; θyi}

Vector de deformaciones

Separado en contribución de membrana y flexión (Moita p. 86):

εxxm = ∂u0/∂x ;  εyym = ∂v0/∂y ;  γxym = ∂u0/∂y + ∂v0/∂x
εxxb = −z·∂θy/∂x ;  εyyb = z·∂θx/∂y ;  γxyb = z·(−∂θy/∂y + ∂θx/∂x)

Matrices Bm y Bb

Obtenidas derivando las funciones de forma:

εm = Bm·ae  ;   εb = Bb·ae
