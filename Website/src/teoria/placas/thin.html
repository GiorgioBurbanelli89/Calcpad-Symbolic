Placa delgada — Teoría Clásica (Kirchhoff / CPT)

Hipótesis de Kirchhoff

  1. Las normales a la superficie media permanecen rectas tras la deformación.
  2. Las normales permanecen perpendiculares a la superficie media deformada (corte transversal despreciable).
  3. El espesor no varía (εz = 0).

Rango de aplicabilidad

Relación espesor/lado menor t / L < 1/20. Para placas más gruesas usa Mindlin-Reissner (FSDT).

Derivación simbólica en Calcpad-Symbolic

El script siguiente deriva las relaciones cinemáticas, las curvaturas, la rigidez a flexión D = E·t³ / 12(1−ν²) y la ecuación biarmónica de gobierno. Las derivadas usan el bloque #sym (simbólico real, no aproximación).

Ecuación de gobierno

D (∂⁴w/∂x⁴ + 2 ∂⁴w/∂x²∂y² + ∂⁴w/∂y⁴) = q

Ecuación biarmónica en w(x,y) con carga transversal q.

Solución navier (placa rectangular simplemente apoyada)

Para carga sinusoidal q = q0·sin(π·x/a)·sin(π·y/b):

wmax = q0 / [D·π⁴·(1/a² + 1/b²)²]
