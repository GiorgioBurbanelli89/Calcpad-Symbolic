Directivas principales

  • "Titulo" — título de sección
  • 'comentario — texto en párrafo
  • #deq expr @@(N) — ecuación displayed, con numeración
  • #sym … #end sym — bloque simbólico
  • #function f(x;y) … #end function — función usuario
  • #hide / #show — ocultar/mostrar definiciones
  • #for i = 1 : n … #loop — ciclo
