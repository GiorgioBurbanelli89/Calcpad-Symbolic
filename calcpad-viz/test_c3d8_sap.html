Tutorial C3D8 — Validación Visual Colormap estilo SAP2000

Cubo 1000×1000×1000 mm, E=22000 MPa, ν=0.2, P=100 kN compresión

1) Desplazamiento UZ (mm) — gradiente vertical

Base UZ=0, Top UZ=-0.004545 mm. Debería verse: azul(min=-0.004545) abajo→rojo(max=0) arriba usando colormap SAP2000 invertido.

2) σ_zz (MPa) — esfuerzo vertical

Compresión uniforme σ=-0.1 MPa. Nudos base=0, nudos top=-0.1 MPa.

3) Gradiente X simulado (estilo Ux del SAP2000 screenshot)

Imitación del contorno Ux del SAP2000. El cubo debe mostrar gradiente diagonal magenta→rojo→amarillo→verde→azul.
